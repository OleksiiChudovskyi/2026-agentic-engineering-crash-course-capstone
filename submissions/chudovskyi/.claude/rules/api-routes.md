# Adding a REST API route

## 0. Pick the route kind first
- CRUD over a DB model → **JSON:API resource** (like `/prompts`, `/categories`, `/tags`). Go to section B.
- Action / integration / anything that is not plain CRUD → **plain `APIRouter`** (like `POST /api/v1/gemini/request`). Go to section A.
- Auth and users routes are generated by FastAPI Users (`app/api/v1/auth.py`, `app/api/v1/users.py`). Never hand-write login/register/users endpoints.

## A. Plain `APIRouter`
1. Add the prefix as a field of `ApiV1PrefixConfig` in `app/config/components/api_config.py`. Never hardcode a prefix string in `include_router`.
2. Create `app/api/v1/<name>.py` with `router = APIRouter(tags=["<Name>"])` and relative paths (`"/request"`), as in `app/api/v1/gemini.py`.
3. Register it in `app/api/v1/__init__.py`: `router.include_router(<name>_router, prefix=settings.api.v1.<name>)`. Do not add routers in `app/server/server.py`.
4. Protection comes from `current_active_user` / `current_active_superuser` (`from .dependencies import ...`). The v1-level `HTTPBearer(auto_error=False)` (`app/api/v1/dependencies/http_bearer.py`) does NOT protect anything; it only adds the auth button to OpenAPI.
5. Dependencies use `Annotated[T, Depends(...)]`. The DB session is only `Depends(db_helper.session_getter)`; tests override exactly this callable (`tests/fixtures/client.py`), so never open your own session.
6. Handlers are `async def` and thin. Logic goes to `app/services/<name>.py` (export in `app/services/__init__.py`); request/response schemas are Pydantic v2 in `app/schemas/<name>.py` (export in `app/schemas/__init__.py`), with constraints via `StringConstraints` / `annotated_types` as in `app/schemas/gemini.py`.
7. Import service functions into the router module by name (`from services import fn`). Tests patch them at `api.v1.<module>.<fn>` (see `tests/test_router_gemini.py`).
8. New routes declare `response_model` and an explicit `status_code` (`fastapi.status` constants) and raise `HTTPException` for client errors. Existing routes do not do this yet; do not rewrite them as a side effect.
9. Imports are relative to `app/` (`from config import settings`, `from models import User`).

## B. JSON:API resource (FastAPI-JSONAPI)
1. Model in `app/models/` (export in `app/models/__init__.py`) plus a **new** Alembic revision. Never edit an existing revision.
2. Read / Create / Update schemas inherit `fastapi_jsonapi.schema_base.BaseModel`; relationships use `Annotated[..., RelationshipInfo(resource_type=..., many=...)]` (see `app/schemas/category.py`, `app/schemas/prompt.py`). Export them in `app/schemas/__init__.py`.
3. Register in `build_jsonapi_app` (`app/api/v1/prompts.py`) before `builder.initialize()`:
   `builder.add_resource(path="/<plural>", tags=["<Name>"], resource_type="<singular>", view=GenericView, model=..., schema=<Read>, schema_in_post=<Create>, schema_in_patch=<Update>)`.
4. Permissions come from `GenericView` (`app/api/v1/dependencies/generic_view.py`): CREATE/GET/GET_LIST/UPDATE need an active user, DELETE/DELETE_LIST need a superuser. For different permissions create a separate view class; do not change the shared `GenericView`.
5. FastAPI-JSONAPI is not in Context7. Read the installed source in `site-packages/fastapi_jsonapi/` under `.venv/` (Linux/Docker: `.venv/lib/python3.11/site-packages/`, Windows: `.venv/Lib/site-packages/`). On this host there is no `.venv`; the source is in the test image (`docker compose -f compose.test.yml run --rm api_test ...`).

## C. Tests (`tests/test_router_<name>.py`)
- A test class marked `@pytest.mark.asyncio`, using fixtures `ac`, `api_prefix`, `auth_headers`; URLs are `f"{api_prefix}/<name>/..."`.
- Cover at least: success, 401 without `auth_headers`, 422 on an invalid body; 403 for superuser-only operations (see the DELETE test in `tests/test_router_prompt.py`).
- Mock external services (Gemini) with `patch("api.v1.<module>.<fn>", new_callable=AsyncMock)`.
- JSON:API payloads are `{"data": {"type": "<singular>", "attributes": {...}}}`, and collection URLs end with `/` (`f"{api_prefix}/prompts/"`).

## D. Done when
- The route is listed in `README.md` → "Basic API Endpoints (v1)".
- `uv run ruff check app`, `uv run ruff format --check app` and `uv run pytest` are green.
